# Test Plan — Newsletter Email Subscription

Created: 2026-09-19
Requirement อ้างอิงจาก: `00-pre-source-ingest.md` (source-ingest, **Pending Review** — ยังไม่มีคนอนุมัติผ่าน QA Review & Sign-off ณ ตอนวางแผนนี้ ใช้เนื้อหาที่มีอยู่ตอนนี้ไปพลางก่อน)

## 1. Objective

รอบทดสอบนี้ทำเพื่อยืนยันว่าฟีเจอร์สมัครรับข่าวสารทางอีเมลใน Footer ทำงานถูกต้องครบทั้ง 3 พฤติกรรมหลัก (ตรวจรูปแบบอีเมล ป้องกันสมัครซ้ำ บันทึกลงฐานข้อมูลพร้อมข้อความสำเร็จ) และให้ความสำคัญเป็นพิเศษกับจุดที่ Requirement ต้นทางยังไม่ปิดจบเรื่อง case-sensitivity ของการเช็คอีเมลซ้ำ ก่อนตัดสินใจปล่อยขึ้น Production — รายละเอียดจุดที่ยังไม่มีคำตอบอยู่ใน Open Questions ข้อ 11

## 2. Scope

**In-scope**
- Validation รูปแบบอีเมล (ถูกต้อง/ไม่ถูกต้อง)
- การป้องกันสมัครซ้ำด้วยอีเมลเดิม (รวมกรณี case ต่างกัน)
- การบันทึกอีเมลสำเร็จและข้อความแจ้งผล
- การกันกดปุ่มซ้ำระหว่างประมวลผล (double submit)

**Out-of-scope**
- Double Opt-in ทางอีเมล — ตามสเปก SRC-001 ระบุชัดว่าเป็นแผน v2
- หน้า Unsubscribe ในตัวฟีเจอร์ — ตามสเปก SRC-001 ให้ผ่าน Support แทนใน v1

**ยังไม่ตัดสินใจว่าจะรวมในขอบเขตหรือไม่ (ดู Open Questions)**
- การทำให้เช็คอีเมลซ้ำแบบ case-insensitive — ยังไม่มีคำตอบสุดท้ายจากทีม Marketing ตาม Slack log (SRC-002)

## 3. ประเภทการทดสอบที่จะทำ

| ประเภท | ดำเนินการในรอบนี้หรือไม่ | หมายเหตุ/เหตุผล |
|---|---|---|
| Functional | ดำเนินการ | ทดสอบ Business Rule ทั้ง 4 ข้อตามสเปก |
| Regression | ไม่ดำเนินการในรอบนี้ | ฟีเจอร์ใหม่ ยังไม่มีของเดิมให้ Regression |
| Integration | ยังไม่ระบุ | ขึ้นกับว่าระบบ subscriber เชื่อมกับระบบอีเมลภายนอกหรือไม่ ยังไม่มีข้อมูลนี้ใน Requirement ต้นทาง |
| Compatibility | ยังไม่ระบุ | ยังไม่มีรายชื่อ Browser/Device ที่ต้องรองรับจาก Requirement ต้นทาง |
| Security | ไม่ดำเนินการในรอบนี้ | ไม่มีการ Login/ข้อมูลอ่อนไหวในฟีเจอร์นี้ นอกเหนือขอบเขตรอบนี้ |
| UAT | ยังไม่ระบุ | ยังไม่มีข้อมูลว่าทีม Product ต้องการ UAT รอบแยกหรือไม่ |

## 4. สภาพแวดล้อมการทดสอบ

## 5. ข้อมูลทดสอบ (Test Data)

- ชุดอีเมลทดสอบ: รูปแบบถูกต้อง/ไม่ถูกต้อง, อีเมลที่สมัครซ้ำแบบตัวพิมพ์เดียวกัน, อีเมลที่สมัครซ้ำแบบตัวพิมพ์ต่างกัน (เช่น `Test@Mail.com` vs `test@mail.com`) — ใช้อีเมลปลอมบนโดเมนทดสอบเท่านั้น ไม่ใช้อีเมลจริงของบุคคล
