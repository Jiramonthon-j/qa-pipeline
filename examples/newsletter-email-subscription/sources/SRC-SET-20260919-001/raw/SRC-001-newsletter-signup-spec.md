# Spec: Newsletter Email Subscription (v1)

**เขียนโดย:** Nan (Product)
**วันที่:** 2026-09-10

## เป้าหมาย

เพิ่มช่องกรอกอีเมลใน Footer ของเว็บไซต์ ให้ผู้ใช้ทั่วไป (ไม่ต้อง Login) สมัครรับข่าวสารทางอีเมลได้

## UI

- ช่อง input เดียว: "อีเมลของคุณ" + ปุ่ม "สมัครรับข่าวสาร"
- แสดงผลแบบ inline ใต้ปุ่ม ไม่ใช่ popup

## Business Rule

1. ต้องกรอกในรูปแบบอีเมลที่ถูกต้อง (มี `@` และโดเมน) ไม่งั้นขึ้น error: "กรุณากรอกอีเมลให้ถูกต้อง"
2. ถ้าอีเมลนี้เคยสมัครไปแล้ว ห้ามสมัครซ้ำ ขึ้น error: "อีเมลนี้สมัครรับข่าวสารไปแล้ว"
3. ถ้าผ่านทั้ง 2 ข้อ → บันทึกอีเมลลงฐานข้อมูล subscriber แล้วขึ้นข้อความสำเร็จ: "สมัครรับข่าวสารสำเร็จ ขอบคุณที่ติดตามเรา"
4. ปุ่ม "สมัครรับข่าวสาร" กดซ้ำระหว่างที่ระบบกำลังประมวลผลไม่ได้ (กัน double submit)

## Out of Scope (v1)

- ไม่ต้องมี Double Opt-in (ไม่ต้องส่งอีเมลยืนยันก่อนนับว่าสมัครสำเร็จ) — เอาไว้คุยกันอีกทีถ้าจะทำ v2
- ไม่ต้องมีหน้า Unsubscribe ใน v1 (ทำผ่านการติดต่อทีม Support ไปก่อน)
