### 2. Feature Overview

เพิ่มช่องกรอกอีเมลใน Footer ของเว็บไซต์ ให้ผู้เข้าชมทั่วไป (ไม่ต้อง Login) สมัครรับข่าวสารทางอีเมลได้ในคลิกเดียว เป้าหมายทางธุรกิจคือขยายฐานรายชื่อผู้รับข่าวสารสำหรับทีม Marketing โดยไม่เพิ่มความซับซ้อนของหน้าเว็บ ฟีเจอร์นี้เล็กและตั้งใจให้ปล่อยเร็ว (v1) แล้วค่อยเพิ่ม Double Opt-in และหน้า Unsubscribe ในตัวทีหลัง (v2)

### 4. ขอบเขต (Scope)

**In-scope**
- Validation รูปแบบอีเมล
- ป้องกันการสมัครซ้ำด้วยอีเมลเดิม
- บันทึกอีเมลสำเร็จ + ข้อความแจ้งผล
- กันกดปุ่มซ้ำระหว่างประมวลผล (double submit)

**Out-of-scope**
- Double Opt-in ทางอีเมล (แผน v2 ตามสเปก)
- หน้า Unsubscribe ในตัวฟีเจอร์ (ผ่าน Support แทนใน v1)

**ยังไม่ตัดสินใจว่าจะรวมในขอบเขตหรือไม่**
- การเช็คอีเมลซ้ำแบบ case-insensitive (ดู BR-002 และ Open Questions)

ขอบเขตที่นี่ตรงกับที่ระบุใน Test Plan (TP-20260919-001) ไม่มีจุดขัดแย้งเพิ่มเติมระหว่างสองไฟล์

### 9. User Flow

**Main Flow**
1. ผู้ใช้กรอกอีเมลที่ถูกต้องและยังไม่เคยสมัคร ในช่อง Footer
2. กดปุ่ม "สมัครรับข่าวสาร"
3. ระบบตรวจรูปแบบอีเมล → ผ่าน
4. ระบบตรวจว่าอีเมลนี้เคยสมัครหรือยัง → ยังไม่เคย
5. ระบบบันทึกอีเมลลง subscriber และแสดงข้อความ "สมัครรับข่าวสารสำเร็จ ขอบคุณที่ติดตามเรา"

**Alternative / Error Flow**
- A1: ผู้ใช้กรอกอีเมลรูปแบบไม่ถูกต้อง → ระบบแสดง "กรุณากรอกอีเมลให้ถูกต้อง" ไม่บันทึกข้อมูล
- A2: ผู้ใช้กรอกอีเมลที่เคยสมัครไปแล้ว (ตัวพิมพ์ตรงกันทุกตัวอักษร) → ระบบแสดง "อีเมลนี้สมัครรับข่าวสารไปแล้ว" ไม่บันทึกซ้ำ
- A3 (Edge case ที่ยังไม่ชัดเจน): ผู้ใช้กรอกอีเมลที่เคยสมัครไปแล้วแต่ตัวพิมพ์ต่างกัน (เช่น `Test@Mail.com` หลังจากเคยสมัครด้วย `test@mail.com`) → ตามพฤติกรรมปัจจุบัน (BR-002 exact match) ระบบจะ**ยอมให้สมัครซ้ำได้** ซึ่งอาจไม่ตรงกับความคาดหวังของผู้ใช้ทั่วไปที่มองว่าอีเมลเดียวกัน — ดู RISK-001
- A4: ผู้ใช้กดปุ่มซ้ำระหว่างระบบกำลังประมวลผล → ปุ่มถูก disable ไว้แล้วตาม BR-004 ป้องกัน double submit

### 17. Draft Acceptance Criteria (Given-When-Then)

- **AC-001 (REQ-F-001)** Given ผู้ใช้เปิดหน้าเว็บใดก็ตามที่มี Footer, When หน้าโหลดเสร็จ, Then ต้องเห็นช่อง input "อีเมลของคุณ" และปุ่ม "สมัครรับข่าวสาร"
- **AC-002 (REQ-F-002)** Given ผู้ใช้กรอกอีเมลรูปแบบไม่ถูกต้อง (เช่นไม่มี `@`), When กดปุ่ม "สมัครรับข่าวสาร", Then ต้องเห็น error "กรุณากรอกอีเมลให้ถูกต้อง" แบบ inline และไม่มีการบันทึกข้อมูล
- **AC-003 (REQ-F-003)** Given อีเมลนี้เคยสมัครไปแล้ว (ตัวพิมพ์ตรงกันทุกตัว), When กดปุ่ม "สมัครรับข่าวสาร" ด้วยอีเมลเดิม, Then ต้องเห็น error "อีเมลนี้สมัครรับข่าวสารไปแล้ว" และไม่มีการบันทึกซ้ำ
- **AC-004 (REQ-F-004)** Given อีเมลถูกต้องและยังไม่เคยสมัคร, When กดปุ่ม "สมัครรับข่าวสาร", Then ต้องเห็นข้อความ "สมัครรับข่าวสารสำเร็จ ขอบคุณที่ติดตามเรา" และอีเมลถูกบันทึกลง subscriber
- **AC-005 (REQ-F-005)** Given ระบบกำลังประมวลผลคำขอสมัครก่อนหน้า, When ผู้ใช้กดปุ่ม "สมัครรับข่าวสาร" ซ้ำในช่วงนั้น, Then ปุ่มต้องอยู่ในสถานะ disable และไม่ส่งคำขอซ้ำ
